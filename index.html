📜 캐릭터 시트 핵심
  • 정체성 / 능력치 / HP·MP / 장비 / 기술을 관리합니다.
  • 스탠딩 연출: 포트레이트와 추가 스탠딩 이미지/영상을 URL + 표정·상황 태그로 줄 단위로 등록합니다. ＋ 버튼으로 줄을 추가하고 ✕로 삭제하세요.
  • 채팅에서 “스탠딩” 토글을 켜면 등록한 태그(예: 미소, 분노) 중에서 골라 띄울 수 있어요.
  • 포트레이트가 있으면 스탠딩 1번은 포트레이트가 되고, 추가 외부 URL은 그 다음 번호로 이어집니다.
  • 상태이상을 누르면 저장되고, 연동된 토큰 위에 상태 배지가 표시됩니다.
  • HP/MP가 바뀌면 연동된 토큰의 HP/MP 바도 함께 갱신됩니다.
시트가 너무 길게 느껴지면 필요한 섹션만 펼쳐서 쓰면 됩니다. 전투 중에는 HP/MP, 장비, 기술만 주로 보면 됩니다.
🎬 장면과 토큰
  • GM 도구의 🎬 장면에서 여러 장면을 만들고, 체크한 장면 하나가 메인 현재 화면에 표시됩니다.
  • 장면마다 배경 이미지/영상, 토큰 배치, 설명, BGM, 필터, 전환효과를 따로 저장합니다.
  • 접속을 종료하고 다시 들어와도 마지막에 보던 장면이 그대로 복원됩니다. 그 장면이 삭제된 경우에만 첫 장면으로 폴백합니다.
  • 토큰은 외부 이미지 / GIF / WEBM / MP4 링크를 사용합니다. 공유 페이지가 아닌 직접 미디어 URL이어야 해요.
  • 토큰을 탭하면 도구 메뉴가 펼쳐집니다 — 🔗 시트 연동 / 📜 시트 보기 / 💥 피격 / 💚 회복. 크기 조절(−/＋), 🗑 삭제, 드래그 이동은 GM 전용입니다.
  • 🔗 시트 연동이 켜져 있으면 시트의 이름·HP/MP 바·상태이상이 토큰에 자동 표시됩니다.
  • 토큰에 데미지·회복이 적용되면 머리 위에 DAMAGE / HEAL 연출이 표시되고, 연동된 시트의 HP/MP도 같이 갱신됩니다.
💬 채팅과 스탠딩
  • 일반 채팅은 우측 패널에 표시됩니다. Enter는 전송, Shift+Enter는 줄바꿈이며, 줄바꿈은 채팅·스탠딩 대사에 그대로 반영됩니다.
  • 스탠딩을 체크하고 메시지를 보내면 메인 화면 우측 하단에 스탠딩과 대사창이 나타납니다.
  • 채팅창에서 이번 대사에 사용할 스탠딩 소스를 선택할 수 있습니다. 시트에 등록한 표정/상황 태그가 그대로 노출됩니다.
  • GM은 발화자(GM / NPC / 몬스터)를 선택할 수 있고, 시트를 고르면 그 시트의 스탠딩만 선택지에 표시됩니다.
  • 대사는 타자기 효과로 출력되며, 여러 대사가 들어오면 순서대로 재생됩니다.
  • 긴 대사가 들어오면 대사창 높이가 자동으로 늘어나고, 그래도 안 들어가면 박스 안에서 자동 스크롤됩니다.
  • 대사창 한 번 클릭: 타이핑 중이면 전체 표시, 다시 클릭하면 다음 대사로 넘어갑니다.
  • 대사창/스탠딩을 더블클릭하면 짧은 페이드로 즉시 끄고 대기 중인 다음 대사들도 함께 비웁니다.
  • 채팅 매크로: /피해 N(HP −N), /회복 N(HP +N), /mp N(MP ±N), /대사 ...(스탠딩 강제 ON). 입력창 옆 -HP / +HP / -MP 단축 버튼도 있습니다.
⚄ 판정 / HP·MP 반영
  • 좌하단 ⚄ FAB 또는 우상단 판정 버튼으로 모달을 엽니다.
  • 능력치 두 개를 선택하고 장비/기술/추가 보정을 더해 굴립니다. 두 주사위가 모두 1이면 펌블, 같은 눈이 6 이상이면 대성공입니다.
  • 목표치를 넣으면 합계가 목표치 이상일 때 성공으로 판정합니다. HP/MP는 토큰 위 💥/💚 버튼으로 수동 반영합니다.
  • 주사위 굴림 필요 없음을 체크하면 포션·회복·MP 소모처럼 효과만 로그로 남길 수 있습니다.
  • 결과 팝업 끄기를 체크하면 주사위 로그만 남고 화면 중앙 결과 연출은 뜨지 않습니다.
  • 굴림 결과 팝업은 주사위 모달 위에 떠올라 굴린 본인도 즉시 결과를 확인할 수 있습니다.
예: 공격은 판정 모달에서 굴리고, 실제 HP 감소는 장면의 적 토큰을 탭해 💥 버튼으로 적용 — 합계 입력 후 적용하면 토큰 위에 데미지 연출이 뜹니다.
🎧 오디오 설정 (효과음 · BGM)
  • 좌하단 🎚 버튼을 누르면 내 브라우저에만 적용되는 오디오 패널이 열립니다.
  • 효과음(무기·피격·크리티컬) — 켜기/끄기 + 음량 슬라이더. GM이 설정한 효과음 URL과 합성음 모두 이 음량을 따릅니다.
  • BGM — 켜기/끄기 + 음량 슬라이더. GM이 트랙별로 정한 음량 위에 곱해지는 개인 배율이라, 방 전체에는 영향을 주지 않습니다.
  • BGM 칩 클릭으로 빠르게 음소거/해제할 수도 있고, 그 상태가 패널과 자동으로 연동됩니다.
  • 설정은 새로고침/재접속해도 유지됩니다.
🛠 GM 도구
🎭 NPC (＋ 울티마 / 악당)NPC 시트, 울티마 포인트, 악당까지 한 탭에 통합. NPC 폼의 ☠ 악당 체크박스를 켜면 등급(일반/엘리트/챔피언/솔로)과 HP/MP 추적이 활성화됩니다. 새로 악당으로 체크하면 GM 화면에만 붉은 등장 연출이 표시돼요. 상단에 울티마 포인트 미니 패널(−/＋/⟳)이 있습니다.
◴ 시계경계 발령·의식·붕괴 같은 진행 시계를 만들고 칸을 채우거나 비웁니다. 모두에게 공개됩니다.
🐉 몬스터레벨·종·등급·능력치·피해 친화도와 공격/스킬을 카드로 관리하고 방 전체에 공유합니다.
🎬 장면배경, 토큰, 설명, BGM, 필터, 전환효과를 장면 단위로 저장합니다. 체크한 장면이 메인에 표시됩니다.
🎵 BGM유튜브/오디오 URL 트랙을 등록하고 트랙별 음량·반복을 정합니다. 플레이어는 각자 자기 음량을 추가로 조절할 수 있어요.
🔊 효과음장비 카테고리별 효과음 URL을 지정합니다. 판정 시 선택한 카테고리에 맞춰 재생됩니다.
✨ 연출현재 장면에 큰 텍스트를 띄웠다 사라지게 합니다. 채팅창에도 시스템 메시지로 기록이 남습니다.
토큰 크기·삭제토큰의 −/＋ 크기 조절과 🗑 삭제, 드래그 이동은 GM 전용입니다.
안전 설정플레이어 토큰 조작 허용, 이동 잠금, 삭제 확인 같은 실수 방지 옵션을 조정합니다.
✨ 텍스트 연출 (GM)
  • GM 도구의 ✨ 연출 탭에서 텍스트를 입력하면 현재 장면 위에 모래처럼 모였다 흩어지는 연출이 떠오릅니다.
  • 크기 4단계(작게/보통/크게/웅장하게), 테두리 색, 광원 세기를 조절할 수 있고 줄바꿈도 그대로 반영됩니다.
  • 방의 모든 사람에게 동시에 표시되고, 사라진 뒤에도 채팅창에 시스템 메시지로 기록이 남습니다(예: ✨ 연출 — ...).
  • 퀵가이드/도움말 같은 모달이 열려 있을 때는 모달 뒤로 자연스럽게 가려져서 모달을 가리지 않습니다.
  • 막 전환, 보스 등장, 중요한 내레이션 강조 등에 활용하세요.
  • NPC 시트에서 새로 ☠ 악당으로 체크한 경우에도 GM 본인에게만 진홍색 등장 연출이 자동으로 표시됩니다.
💾 백업 / 문제 해결
  • 세션 전에는 방 전체 백업(💾 버튼)을 추천합니다.
  • 외부 링크 이미지는 공유 페이지 주소가 아니라 직접 이미지 주소여야 합니다.
  • 영상 토큰/스탠딩은 WEBM 또는 MP4 직접 링크를 권장합니다.
  • 스탠딩이 안 뜨면 메인 🎭 또는 채팅창 스탠딩 체크, 시트의 스탠딩 URL을 확인하세요.
  • HP/MP 바가 안 보이면 토큰과 시트가 🔗 연동되어 있는지 확인하세요.
  • 효과음/BGM이 안 들리면 좌하단 🎚 패널에서 켜짐/음량을 확인하세요(이 설정은 내 브라우저에만 적용됨).
  • 재접속 후 장면이 이상하면 GM 도구 🎬 장면에서 원하는 장면을 다시 체크하세요(보통은 자동 복원됨).
  • 동기화가 이상하면 새로고침 전에 먼저 JSON 백업을 저장해두세요.

✦ 첫 모험 준비 ✦
처음 온 플레이어가 1분 안에 시작할 수 있도록 5단계로 정리했습니다.
1. 방 입장

방 코드와 닉네임을 입력합니다. GM 한 명만 GM 체크를 켜고 들어오세요.

2. 시트 작성

우상단 📜 시트로 캐릭터 시트를 열고 이름·능력치·HP/MP·기술·스탠딩 이미지를 채웁니다.

3. 장면 확인

GM이 만든 장면이 메인 현재 화면에 표시됩니다. 토큰은 드래그로 이동, 탭하면 도구 메뉴(💥/💚 피격·회복 · 🔗 연동 · 📜 시트 보기)가 나옵니다. 크기 조절(−/＋)과 삭제는 GM 전용입니다.

4. 토큰 연동

내 토큰의 🔗을 눌러 시트와 연결하면 HP/MP 바와 상태이상이 토큰 위에 표시되고, 시트에서 바뀐 값이 그대로 동기화됩니다.

5. 대사와 판정

화면 좌하단 ⚄ FAB 또는 우상단 판정 버튼으로 주사위를 굴립니다. 채팅에서 🎭 스탠딩을 켜면 대사 연출도 표시됩니다.
